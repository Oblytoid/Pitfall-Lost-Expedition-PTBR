# Pitfall: The Lost Expedition (PS2) — Tradução PT-BR

Ferramentas da tradução de fãs de **Pitfall: The Lost Expedition** (PlayStation 2, SLUS-20408) para o português do Brasil, por **Oblytoid**.

**Para jogar:** baixe o `.zip` em [Releases](../../releases), descompacte e arraste a ISO original em cima de `ARRASTE A ISO AQUI.bat`.

Este repositório não contém o jogo nem arquivos extraídos dele. Você precisa da sua própria cópia original.

## Ferramentas (pasta `ferramentas`)
Scripts em Python 3 que extraem e reinserem os textos (`quickdat.arc` e as cópias em `datasets.arc`, inclusive as compactadas), atualizam o `index.ind`, montam a ISO e geram o patch `.xdelta`. Detalhes em `ferramentas/LEIAME.md`.
